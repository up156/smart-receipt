# 🧾 Smart Receipt — распознавание чеков с аналитикой расходов

**📸 OCR чеков → 🤖 AI-анализ → 📊 Категории и статистика**

---
## 📌 TL;DR

- Запуск за ~3 минуты: всё поднимается одной командой через Docker Compose.
- Pet-проект с элементами промышленной архитектуры: Kafka, Redis, PostgreSQL, мониторинг, AI-интеграция.
- Spring Security с JWT и RBAC (роли: пользователь, админ).
- Demo-режим с заранее созданным пользователем (весь функционал доступен без регистрации).
- Документация: Swagger UI, Postman-коллекция для быстрого старта.

---
## 🚀 Быстрый старт

git clone https://github.com/up156/smart-receipt.git  
cd smart-receipt  
docker compose up --build  
⏳ Время запуска: ~2-3 минуты (с учётом скачивания образов и моделей Tesseract).

## 📝 Регистрация и работа с категориями  
При регистрации автоматически создаются 8 стандартных категорий (овощи, молочные продукты и др.)  
Пользователь может просматривать, создавать, редактировать и удалять категории  
После распознавания чека получить список всех чеков, редактировать опечатки или категории в товарах, получить чек по id.
Также реализована обработка текстовых чеков без OCR (/api/v1/receipt/parse-text)

## 🏗️ Архитектура и интеграции
Kafka используется для публикации событий после парсинга чека (ReceiptParsedEvent): легко расширяется, можно подключать новые сервисы (например, Telegram-бот для уведомлений пользователя об обновлении статистики).  
Listener обновляет статистику пользователя. Метрики обновлений и ошибок видны в Grafana.   
Инфраструктура: PostgreSQL, Redis, Kafka, Prometheus, Grafana, Liquibase.

---
## 🧠 Как работает
📸 Загружается изображение чека  
🔠 OCR (Tesseract) извлекает текст  
🤖 AI (GigaChat или fallback) структурирует список товаров (название, цена, категория)  
_Если основной AI-запрос не удался или вернулся некорректный ответ, сервис выполняет повторную попытку с fallback-промтом (упрощённая инструкция для модели — работает лучше при сложных/испорченных чеках)._  
📬 Kafka публикует ReceiptParsedEvent  
📊 Listener обновляет статистику (всё отображается на Grafana-дэшборде)

   SPRING_PROFILES_ACTIVE=prod
   GIGACHAT_TOKEN=your-token-here
3. Запустите:
   docker compose --env-file .env up --build
